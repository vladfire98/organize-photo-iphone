# organize-photo-iphone
Bash-скрипт для сортировки фоток с IPhone из директории DCIM.

В скрипте необходимо указать SOURCE и DEST директории.
SOURCE - там скрипт будет искать не отсортированные фото и видео
DEST - там скрипт разложит и отсортирует по годам готовые фото/видео

## Зависимости
heif-convert и mediainfo
